# 配套贴文

默认一组照片配一条贴文，按图片顺序概括同一个生活片段，不给每张机械配一句。先看实际成图，再写具体动作、观察或人物当下的轻微感受；不要复制摄影术语、服装清单、镜头参数或整段生图 prompt。

语言优先使用用户本次要求，其次已明确的文案语言偏好，否则沿用当前对话语言。语气服从人物设定。没指定长度时写 1–3 句自然短文，表情和提问可选，不固定使用反问、暧昧邀约或标签串。

不把未定义的人物经历、关系、真实店名、精确天气或未来事件写成已经发生的事实。角色第一人称可表达本次创作情境，不承诺线下活动；不把图里不存在的道具或动作写进去。多图是一个生活事件时保持叙述连续。

需要贴文时只在该组目录保存一份 caption.md，正文可直接复制；不再生成相同内容的 caption.json。图片顺序按实际交付组织，启用拍摄记录也不会自动增加贴文副本。若用户明确要求结构化贴文导出，以其选定格式替换正文文件，而不是默认两种都存。

用户只要拍摄方案但也要求贴文时，可以先拟文案，明确标为拟定场景文案，不冒充基于实际成图。用户明确只要图片、提示词或 JSON 时不额外输出贴文。这里只生成文件与文字，不执行对外操作。
