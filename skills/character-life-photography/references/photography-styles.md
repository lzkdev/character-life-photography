# 日常生活场景与摄影风格

风格是可替换的摄影层。用户自定义风格或参考图优先；预设是起点，没有固定配额和万能镜头。下面焦段均为全画幅等效的视觉意图，不冒充生成图真实 EXIF。

| preset ID | 适合的表达 | 镜头、光线与构图 | 避免机械套用 |
|---|---|---|---|
| natural_daily | 自然日常，默认；家里、工作间隙、散步 | 常用 35–65mm，可信窗光／环境光，适量环境信息，自然肌理 | 不固定笑容、饮料或黄色包 |
| phone_snapshot | 手机随拍，生活接近感 | 常用 24–35mm 等效，合理拍摄距离，较深景深，轻微偏心或手持感；自拍按用户需求 | 不强加 85mm 奶油虚化，不用大广角近距离把脸拉变形 |
| documentary | 生活纪实，事件与环境优先 | 常用 28–50mm，动作中途、环境层次、克制色彩与修饰 | 不把所有照片磨成商业柔肤，不刻意让每张都看镜头 |
| cinematic_daily | 电影感日常，细节与情绪 | 常用 35–85mm，明确的窗／门／灯具光源，前中后景、克制明暗与色彩分离 | 不自动加橙蓝、雨雾、烟、黑夜或戏剧性悲伤 |
| film_daily | 胶片质感，日常的柔和层次 | 常用 35–50mm，自然颗粒、柔和高光过渡、适量暖／冷偏色；具体胶片模拟只按用户指定 | 不将不同肤色一律漂白，不用重颗粒遮挡五官与手部 |
| soft_portrait | 清新生活写真，人物反应突出 | 常用 50–85mm，合适的柔光、较浅景深、干净色盘，保留必要环境 | 夜晚不强制高键日光；没有太阳方向依据不加发丝金边 |
| custom | 用户指定或风格参考 | 把参考拆成机位、景深、光线、色彩、纹理与构图，并标明身份参考另用 | 不继承风格图中另一个人的脸、身材、年龄或穿搭，除非本次明确要求 |

可以组合，例如 phone_snapshot 加 film_daily 的色彩质感；在记录中写 primary 与修饰说明，不把不兼容的全部预设堆到一个 prompt。日常范围涵盖室内外、独处或用户要求的互动；人物数量和镜面规则由本次构图及人物档案决定。

互动是独立的 [镜头关系设置](camera-interaction.md)，不需要牺牲任一种摄影风格。比如 soft_portrait + responsive 可以保留探身听人说话的写真感；film_daily + responsive 可以表现回头等同伴；phone_snapshot + companion 可以表现共同坐在早餐桌边。用户要求回应式互动时，不用“纪实／抓拍”将其自动改成不理镜头。

## 从生活事件选画面

| 情境 | 动作的起点 | 镜头和空间信息 |
|---|---|---|
| 早餐／家务 | 放下杯子、翻烤面包、叠衣物、给植物浇水 | 手与物体接触、台面高度、窗户方向；不把动作变成端盘摆拍 |
| 阅读／兴趣 | 翻页、做标记、调琴弦、整理颜料 | 视线与操作位置合理，手部清楚；内容细节未设定就不编造作品标题 |
| 工作间隙 | 收拾桌面、伸展、听同事说话、走到窗边 | 服装和道具符合角色职业；同事若入镜也需要明确人数与身份要求 |
| 出门／通勤 | 穿外套、确认路线、等灯、整理包带 | 前后场景连贯，背景可辨；不捏造真实班次或精确路线 |
| 购物／散步 | 看清单、停在橱窗边、拎袋转身、绕开积水 | 道具和环境造成动作；积水需情境依据，不随意添加 |
| 休息 | 坐下、望向窗外、放松肩膀、读一条消息 | 安静不等于悲伤；手机内容不可凭空当成角色既有事实 |

## 天气、时间和衣服一起决定

本节适用于日常摄影及采用现实环境的外景。明确的棚拍或其他创作类型按其模块设置环境依据，摄影风格本身不强制触发当前天气查询。

默认使用人物预设位置与当地当前时间查询天气，无需用户点名“今天”。先查询，再依据活动及室内外环境决定天气如何影响画面；预设位置来自人物档案，不来自用户设备定位。用户明确指定的时间／天气覆盖这个默认值。

“阴天”只有漫射光含义，不自动等于雨、湿地、厚衣或低落情绪。降雨概率不能证明正在下雨。雨后湿地需要近期降雨依据或明确创作设定。夜晚使用店铺、路灯或室内实景灯；黄金时段按场景日期和地点判断。

服装结合气温／体感、风雨、活动和室内温度选择；炎热户外避免厚围巾，寒冷场景合理保暖，薄针织和厚针织分开。固定饰品可以戴在衣服外或被遮挡，是否允许取决于人物档案；不能为了露出某个特征让穿衣违背情境。

实际查询仍失败时，可交付不依赖具体天气的条件方案并明确缺口；不能用临时改成室内来省略默认查询，也不把未查询的具体温度写成实况。窗光方向、雨迹、路面干湿与画面里的时间保持一致。

## 地点、色彩和真实感

用户指定地点时使用其依据；没核实精确店铺时描述虚构的区域氛围，标 fictionalized。不要凭地名补造门牌、营业状态、节庆、花季或某日发生的活动。

色彩优先保持人物身份与服装事实。低饱和背景、单一亮色物件只是可选构图方法；纪实或手机场景可以多色、无刻意色块。酒红衣服不能同时写 no red，蓝包不能被 no saturated colors 消除。

浅景深、运动模糊、前景遮挡、颗粒、反射和歪构图按表达需要选用，不同时叠满。镜子与玻璃反射遵从几何与左右关系；重要标记在镜像中翻转不自动判错，先核对是否确为镜像。
